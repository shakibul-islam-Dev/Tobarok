# Tobarok - Realtime E-Commerce Platform with Ad-to-Earn System

Tobarok is a modern, real-time e-commerce platform where users can purchase products such as T-shirts, Shoes, Panjabis, Jerseys, and more using earned points instead of traditional payment methods.

The platform introduces an innovative **Ad-to-Earn** system where users watch advertisements to earn points, which can later be used to purchase products. The application includes fully responsive **User** and **Admin Dashboards**, real-time updates, and a seamless shopping experience.
